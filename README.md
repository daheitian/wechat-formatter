# 见室排版 · 公众号排版助手（Chrome 扩展 + 网页版）

一个轻量的排版工具，帮你把文章套上优雅模板，**一键导出到微信公众号 / Notion / FlowUs**。提供两种形态，复用同一套引擎：

- **Chrome 扩展**：驻在工具栏，可「一键注入」已打开的公众号编辑页（体验最佳）。
- **网页版**（`web/` 目录）：纯网页运行，无需安装，可本地打开或托管到任意静态空间。

## 功能
- **9 套命名模板（参考 Typora / Bear 设计语言，分系列）**：
  - **Typora 系列**（干净文档风）：Typora·GitHub（白底系统字 / GitHub 蓝链 / 浅灰代码底）、Typora·Newsprint（暖白纸感 / 衬线宽行距）、Typora·Pixyll（轻盈灰调 / 克制留白）、Typora·Gothic（现代无衬线 / 几何标题）
  - **Bear 系列**（温暖圆润风）：Bear·暖白（奶油底 / 招牌暖黄高亮 / 大圆角）、Bear·暗夜（暖黑底 / 黄色链）、Bear·衬线（暖调衬线）、Bear·薄荷（柔和薄荷强调）
  - **见室品牌**：见室（黑 + 暖白编辑雕版，圆润版）
  
  风格要点：Typora 系列走「克制字重 + 舒适行距 + 浅灰代码底 + 细分割线 + 低调链接」的纯文档感；Bear 系列走「奶油/暖黑底 + 招牌暖黄(或薄荷)强调 + 10–12px 大圆角 + 亲和留白」。可在 `js/templates.js` 继续扩展。
- **样式收藏**：每张模板卡带 ★ 收藏按钮，顶部「★ 收藏」可只看收藏；收藏列表持久化（chrome.storage / localStorage）。
- **双写作模式**：
  - 富文本模式（WYSIWYG）：标题、加粗、斜体、引用、列表、代码块（自动高亮）、行内代码、分割线、图片、多图网格
  - **Markdown 模式**：左侧写 Markdown、右侧**实时主题预览**，写完/换皮肤即时看效果（对标 huasheng.ai 的「写/美分离」）
- **代码高亮**：零依赖语法高亮（关键字 / 字符串 / 注释 / 数字 / 函数），按模板代码块明暗自动切换配色，输出内联 `span` 完美兼容微信。
- **图片管线**（对标 huasheng）：上传/粘贴图片 → Canvas 压缩（长边 ≤1920、质量 85%）→ **IndexedDB 本地存储** → 编辑器只显示 `img://` 短链（长文不卡、刷新不丢）→ 导出到公众号/下载时才转 base64。
- **多图网格**：一次选多张图，选 2/3 列，自动排成微信友好的 `<table>` 网格。
- **智能粘贴**：从 Notion / Word / 飞书等粘贴带样式的 HTML 时自动净化成干净语义结构（去 style/class、保留加粗/斜体/列表/引用/代码）。
- **.md 导入 / 导出**：导入 `.md` 自动解析成内容；导出 `.md`（图片内联 base64，自包含）或下载 HTML 存档；Markdown 也可直接复制粘贴进 Notion / FlowUs。
- 实时预览：两种模式都即所见即所得地套用模板样式
- **GFM 表格**支持（Markdown ↔ HTML 双向，导出微信用原生 `<table>`）
- 一键导出：
  - 📋 **复制富文本** → 直接 `Ctrl+V` 粘贴进公众号编辑器（全内联样式，微信保留率最高）
  - ⬇ **一键导入公众号** → 自动注入已打开的 `mp.weixin.qq.com` 编辑页（页面右侧出现绿色按钮）
  - 📝 **复制 Markdown** → 直接粘贴进 Notion / FlowUs
  - 📂 **导入 .md** / ⬇ **下载 .md** / 💾 **下载 HTML** → 落盘与互转
- 自动保存草稿（含当前模式、Markdown 源码、图片引用，关闭再打开不丢）

## 加载方式（开发者模式）
1. 打开 Chrome，访问 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本目录 `wechat-formatter/`
4. 固定扩展图标到工具栏，点击即可打开排版面板

> 无需任何服务器或账号，纯本地运行。

## 网页版（web/ 目录）
与扩展共用同一套引擎（`js/` 下的模板、导出、图片管线、高亮、Markdown 解析），无需安装、无扩展 API 依赖。

**用法二选一：**
- **本地直接打开**：双击 `web/index.html`（用 Chrome / Edge / Safari 均可）。注意用 `file://` 打开时浏览器会禁用 IndexedDB，此时图片管线自动降级为「内存 + base64」兜底，导出图片依然正常（见 `js/images.js` 的 `memCache`）。
- **托管为静态站点**：把整个 `wechat-formatter/` 目录（或只取 `web/` + `js/`）部署到任意静态空间（GitHub Pages / Vercel / 对象存储），访问 `web/index.html` 即可。

**网页版与扩展的差异：**
- 网页版**没有「一键导入公众号」按钮**（注入需要扩展权限）——改为点「📋 复制富文本」后到公众号编辑页 `Ctrl+V` 粘贴，体验完全一致。
- 其余功能（14 套模板、收藏、双模式、代码高亮、图片管线、多图网格、智能粘贴、.md 导入导出、草稿自动保存）与扩展版完全相同。
- 网页版界面为**全屏 iOS 27 Liquid Glass 风格**：左侧模板栏、中央工作区、底部导出栏，Markdown 模式为「源码 + 实时预览」双栏。

> 想验证页面能否正常加载，可跑 `node web/test-web.js`（jsdom 冒烟测试，校验 14 模板卡 / 系列分组 / MD 切换预览）。

## 快速预览（不装扩展也行）
推荐直接用浏览器打开 `web/index.html` 体验完整网页版。早期遗留的 `popup.html` 仍是扩展弹窗页面，也可单独打开，但能力略少于网页版（无全屏布局）。

## 各平台导出用法
- **微信公众号**：在扩展里点「复制富文本」，切到公众号编辑页 `Ctrl+V`。或点「一键导入公众号」（需先打开编辑页）。图片会以 base64 随内容上传到微信。
- **Notion**：点「复制 Markdown」，在 Notion 页面 `Ctrl+V`，Notion 会自动把 Markdown 转成块。
- **FlowUs**：同样复制 Markdown 后粘贴；富文本 HTML 也可直接粘贴进 FlowUs 文档。

## 目录结构
```
wechat-formatter/
├── manifest.json        # MV3 扩展配置
├── popup.html/.css/.js  # 排版面板 UI 与逻辑
├── background.js        # service worker（转发导入消息）
├── content.js           # 公众号编辑页注入 + 悬浮导入按钮
├── js/
│   ├── templates.js     # 14 套模板定义 + 内联样式/预览生成 + 明暗检测
│   ├── exporters.js     # 剪贴板 / Markdown 互转 / HTML·MD 下载
│   ├── images.js        # 图片管线：压缩 + IndexedDB + 内存兜底（memCache）
│   ├── highlight.js     # 零依赖代码高亮（内联 span，明暗两版配色）
│   ├── editor.js        # contenteditable 编辑器 / 工具栏 / 多图网格 / 智能粘贴
│   └── markdown.js      # 轻量 Markdown→HTML 解析（无依赖）
├── web/                 # 网页版（复用上面引擎，无扩展依赖）
│   ├── index.html       # 全屏玻璃布局页面
│   ├── web.css          # iOS 27 Liquid Glass 风格
│   ├── web-app.js       # 网页版接线（与 popup.js 同逻辑，去注入依赖 + 修 .md 导入）
│   └── test-web.js      # 网页版加载冒烟测试（jsdom，11 项）
└── test/logic-test.js   # 核心转换逻辑的自动化校验（node 运行，67 项）
```

## 扩展模板
在 `js/templates.js` 的 `TEMPLATES` 数组里加一项即可（定义 `base` 容器样式 + 各元素 `styles` + `series` 系列名 + `accent` 强调色）。新增后画廊会自动出现。

## 说明与边界
- 微信编辑器会过滤部分 CSS，本工具采用「全内联样式」策略以最大化保真；个别复杂装饰（如阴影）在微信端可能被弱化，属平台限制。
- 一键导入依赖公众号 UEditor 的 iframe 结构，若微信改版导致失效，可改用「复制富文本 + 手动粘贴」兜底。
- Markdown 解析为轻量自研实现，覆盖常用语法（标题/粗斜体/代码/引用/列表/分割线/图片/链接/表格/代码围栏）；极复杂嵌套如需可用富文本模式。
